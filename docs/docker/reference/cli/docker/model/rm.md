# docker model rm

**Description:** Remove local models downloaded from Docker Hub

**Usage:** `docker model rm [MODEL...]`










## Description

Remove local models downloaded from Docker Hub


## Options

| Option | Default | Description |
|--------|---------|-------------|
| `-f`, `--force` |  |  Forcefully remove the model |
