# [\#](https://devdocs.krayincrm.com/2.2/prologue/\#prologue) Prologue

Welcome to the **Prologue** — the section that covers everything _around_ the code: how to keep your Krayin install up to date and how to contribute back to the project.

If you're new to Krayin, start at the [Introduction](https://devdocs.krayincrm.com/2.2/introduction/) instead — this section assumes you already have a working install and want to upgrade it or send a patch.

## [\#](https://devdocs.krayincrm.com/2.2/prologue/\#what-s-in-this-section) What's in this section

- [Upgrade Guide](https://devdocs.krayincrm.com/2.2/prologue/upgrade-guide.html) — step-by-step instructions for moving a running Krayin install to the latest release, plus the dependency-change reference.
- [Contribution Guide](https://devdocs.krayincrm.com/2.2/prologue/contribution-guide.html) — how to file bug reports, propose features, pick the right branch, run Pint, and report security vulnerabilities.
