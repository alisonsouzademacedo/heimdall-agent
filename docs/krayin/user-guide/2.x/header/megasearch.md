# [\#](https://docs.krayincrm.com/2.x/header/megasearch.html\#mega-search) Mega Search

**Mega Search** looks across the whole CRM from one field in the header, so a record can be found without first opening the section it belongs to.

### [\#](https://docs.krayincrm.com/2.x/header/megasearch.html\#opening-the-search) Opening the search

**Step-1** Click the search field in the header, or press **Ctrl + K** anywhere in the admin panel. On a Mac, press **⌘ \+ K**.

**Step-2** The search opens as a modal with the field already focused, so you can start typing straight away.

**Step-3** Press **Escape**, or click outside the modal, to close it.

### [\#](https://docs.krayincrm.com/2.x/header/megasearch.html\#searching) Searching

Type at least two characters. The results are grouped into sections, and each section carries a count of how many records it holds for what you typed.

**1) Leads-** Searched by title, sales owner and person.

**2) Quotes-** Searched by subject, description, sales owner and person.

**3) Products-** Searched by name, SKU and description.

**4) Contacts-** Searched by name, job title, sales owner and organization.

**5) Settings-** The settings pages whose names match.

**6) Configuration-** The configuration pages whose names match.

Click a section to see its results, and click a result to open that record.

### [\#](https://docs.krayincrm.com/2.x/header/megasearch.html\#section-counts) Section counts

The badge beside each section name shows how many records that section holds for the term you typed, so you can see where the matches are without opening every section in turn.

**Note- A section that has not been counted yet shows no badge at all, rather than a zero, so a count still being fetched is never mistaken for an empty result. A count above ninety-nine is shown as 99+.**

### [\#](https://docs.krayincrm.com/2.x/header/megasearch.html\#exploring-a-section) Exploring a section

Each section offers an **Explore all** link beneath its results. It carries what you typed into that section's own listing, where the full set of matches can be filtered, sorted and paged through.
