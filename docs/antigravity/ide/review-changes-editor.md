# Review changes

After the agent begins writing code within a conversation, a `Review Changes` section appears in the Agent panel’s [bottom toolbar](/docs/ide/agent-side-panel). Click it to open a pane in your editor where you can scroll through all of the changes that you and your agent made during the conversation.

![Editor Review Changes](/assets/image/docs/editor/review_changes_editor.png)

Just like with artifacts, you can comment on any of the file diffs to communicate with the agent.
